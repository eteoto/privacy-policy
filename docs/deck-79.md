# DECK 79 プライバシーポリシー

最終更新日: 2026/10/19

## 1. はじめに

DECK 79（以下「本アプリ」）は、Apple Musicの楽曲を操作するカセットデッキ風のミュージックプレイヤーアプリです。本プライバシーポリシーは、本アプリにおける情報の取り扱いについて説明するものです。

## 2. 収集する情報

### 2.1 個人情報

本アプリは、ユーザーの個人情報（氏名、メールアドレス、電話番号等）を収集しません。また、アカウント登録機能はありません。

ただし、お問い合わせの際にお送りいただいたメールアドレスや本文は、お問い合わせへの対応に使用します。

### 2.2 使用情報

本アプリは、以下の情報にアクセスします。

- Apple Musicの再生情報（曲名、アーティスト名、アルバム名、楽曲識別子、ジャケット画像等）
- ミュージックライブラリの情報
- 再生状態（再生中／停止中、再生位置、シャッフル設定、リピート設定等）
- 端末の音量

これらの情報は、アプリの機能を提供するためにのみ使用されます。開発者のサーバーへの送信や保存は行いません。

楽曲情報やジャケット画像、配色情報を取得するため、Appleが提供するサービスや画像配信先と通信する場合があります。その際、楽曲識別子等の取得に必要な情報が送信され、通信先ではIPアドレス等の通信に伴う情報が取り扱われる場合があります。

### 2.3 端末内に保存する情報

本アプリは、アルバムごとのカセットの種類や、その割り当てに必要なアルバム識別情報を端末内に保存します。これらの情報を開発者のサーバーへ送信することはありません。

端末内に保存された設定は、本アプリを削除することで削除できます。端末のバックアップに含まれる情報は、利用するバックアップサービスの設定に従って取り扱われます。

ミュージックライブラリ等へのアクセス許可は、iOSの「設定」から変更できます。アクセスを許可しない場合、一部の機能が利用できなくなることがあります。

## 3. 情報の使用目的

本アプリがアクセスする情報は、以下の目的でのみ使用されます。

- Apple Musicで再生中の曲情報を画面に表示するため
- 再生／一時停止、曲送り、頭出し、シャッフル、リピート等の操作を実行するため
- シークや音量調整機能を提供するため
- ジャケットに応じたカセットの配色を表示するため
- アルバムごとに割り当てたカセットの種類を保持するため

## 4. 第三者への情報提供

本アプリは、上記の機能提供に必要なAppleのサービス等との通信を除き、ユーザーの音楽情報や設定を第三者に提供、共有、または販売することはありません。また、広告配信サービスやアクセス解析ツールも使用していません。

Appleのサービスにおける情報の取り扱いについては、以下のプライバシーポリシーをご確認ください。

Appleのプライバシーポリシー：

https://www.apple.com/jp/legal/privacy/
