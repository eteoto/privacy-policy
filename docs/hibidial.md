# HibiDial プライバシーポリシー

更新日：2026年10月11日

公開URL：https://eteoto.github.io/privacy-policy/hibidial

## 保存するデータと用途

HibiDialは、予定の名前・時刻・色・固定設定、曜日ごとの予定、日付ごとの変更、通知設定を端末内に保存します。予定の表示、ホーム画面のウィジェット、開始通知に使用します。旧版から復元した利用記録も端末内だけに保持します。

## 収集・送信・第三者提供

HibiDialの開発者は、アプリから予定や端末情報を収集しません。アプリ内に広告、アクセス解析、追跡、アカウント登録、開発者サーバーへの同期機能はありません。予定はアプリと同じ端末のウィジェットで共有します。

## 権限と通知

開始通知を有効にすると、OSに通知の許可を求めます。通知は端末内で予約します。許可しなくても予定とウィジェットを利用できます。通知の許可は端末の設定で変更できます。カメラ、マイク、位置情報、連絡先は使用しません。

## バックアップと外部サービス

バックアップは、利用者が選んだ保存先や共有先へJSONファイルとして渡します。保存先・共有先のサービスには、そのサービスの規約とプライバシーポリシーが適用されます。バックアップには予定が含まれ、パスワードによる暗号化はされません。共有先を確認して保管してください。OSによる端末バックアップやストアの診断情報は、Apple・Googleの設定とポリシーに従います。

## 保護・保持・削除

予定はOSが管理するアプリ領域に保存し、ウィジェットだけが必要なデータを読み取ります。利用者が削除するまで保持します。「設定 → すべての予定データを削除」から予定・日別変更・通知設定・旧版の利用記録と、アプリが用意したバックアップの一時ファイルを削除できます。外部へ保存・共有したバックアップは、保存先で別途削除してください。OSのバックアップを削除する場合は、端末の設定から操作してください。
