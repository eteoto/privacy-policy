# 振動メトロノーム - スマホの振動でテンポを刻む プライバシーポリシー

最終更新日: 2026-10-09

## 1. アプリの概要

振動メトロノーム - スマホの振動でテンポを刻むは、音を出さずに端末の振動と視覚表示でテンポを確認するメトロノームアプリです。ポケット利用を想定したフォアグラウンド専用の表示モードを備えています。

## 2. 収集・送信される情報

本アプリ自体には、アカウント登録や氏名、メールアドレス、電話番号などを入力・収集する機能はありません。

本アプリは広告配信のために Google AdMob（Google Mobile Ads SDK）を使用しています。広告の表示、効果測定、不正利用防止、サービス改善などのため、Googleが以下の情報を自動的に収集または処理する場合があります。

- IPアドレス（おおまかな位置情報の推定に使用される場合があります）
- アプリの起動、広告の表示・タップなどの利用・操作情報
- SDKやアプリの動作、クラッシュ、パフォーマンスなどの診断情報
- 広告ID、App Set ID、その他の端末またはアカウントに関連する識別子
- 端末情報、OS情報など広告配信に必要な技術情報

実際に処理される情報は、利用地域、端末やOSの設定、Googleの設定、配信される広告の種類、ユーザーの同意状況などによって異なる場合があります。Googleによる情報の取り扱いについては、以下をご確認ください。

- [Google パートナーのサイトやアプリを使用する際の Google によるデータ使用](https://policies.google.com/technologies/partner-sites?hl=ja)
- [Google プライバシーポリシー](https://policies.google.com/privacy?hl=ja)

## 3. 端末内に保存する情報

本アプリは、使いやすさのために以下の設定を端末内に保存します。

- BPM
- 拍子
- カウントイン設定
- 振動設定
- 視覚表示設定
- 画面スリープ防止設定
- テーマ設定

これらのアプリ設定は端末内にのみ保存され、開発者または第三者のサーバーへ送信されません。ただし、前項に記載した広告配信に伴う情報はGoogleへ送信される場合があります。

## 4. 第三者サービス・外部送信

本アプリは、バナー広告の配信にGoogle AdMobを使用し、広告リクエストに必要な情報をGoogleへ送信します。Googleは、広告配信、広告のパーソナライズ、効果測定、分析、不正利用防止などの目的で情報を処理する場合があります。

本アプリは、Google AdMob以外の分析SDK、クラウド同期、ログイン機能を使用していません。

## 5. 広告とプライバシー設定

表示される広告は、利用地域、端末設定、Googleの広告設定、同意状況などに応じて、パーソナライズ広告、非パーソナライズ広告、または制限付き広告となる場合があります。広告のパーソナライズは、端末またはGoogleアカウントの広告設定から管理できる場合があります。

法令またはGoogleのポリシー上必要な地域では、広告に関する情報の利用について同意画面やプライバシー設定を提供する必要があります。公開時には、実際の配信地域と同意管理の実装が適用要件を満たしていることを確認します。

## 6. 権限の利用

Android版では、端末の振動を利用するために通常権限 `android.permission.VIBRATE` を使用します。この権限は振動メトロノーム機能と振動テストのためだけに使用します。

iOS版では、端末の触覚フィードバックを使用します。通知、バックグラウンドオーディオ、位置情報、マイク、カメラ、連絡先などの権限は使用しません。

## 7. データ削除

アプリ内の「設定を初期化」により、保存された設定を初期値へ戻せます。また、アプリをアンインストールすると端末内に保存された設定は削除されます。

本アプリはアカウントを作成しないため、アカウント削除機能はありません。Googleが広告配信に関連して処理する情報の管理・削除については、端末およびGoogleアカウントのプライバシー設定をご確認ください。

## 8. 注意事項

- 本アプリは音を出さず、振動でテンポを伝えるアプリです。
- ポケット利用を想定していますが、端末を安全に保持できる状況で使用してください。
- 本アプリはフォアグラウンドのみ動作します。
- バックグラウンドまたは画面ロックでは停止します。
- 端末やOS設定により振動の強さ、長さ、体感には差があります。
- OSや端末状態によりタイミングが揺れる場合があり、完全なタイミング精度は保証しません。
- 本アプリは医療機器、健康管理機器、専門計測器ではありません。

## 9. ポリシーの変更

アプリの機能変更によりデータの取り扱いが変わる場合、本ポリシーを更新します。公開後は、更新日を明記します。
